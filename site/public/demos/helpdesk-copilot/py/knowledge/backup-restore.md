# Restoring deleted files and backups

Files in OneDrive and SharePoint can be restored by yourself. Files on the file server
(S: drive) are backed up every night and IT restores them on request.

## Restore a deleted file from OneDrive or SharePoint

Open OneDrive or the SharePoint site in the browser and click **Recycle bin**. Select the file
and click **Restore**. Deleted files stay in the recycle bin for 93 days.

## Get an older version of a document

In OneDrive or SharePoint, right-click the file and choose **Version history**. Open an older
version to check it and click **Restore** to make it the current version. This also helps
after a file was overwritten by mistake.

## Request a restore from the file server backup

The S: drive is backed up every night at 01:00 and backups are kept for 30 days. Send the IT
desk a restore request with:

- the full path of the file or folder, for example `S:\Finance\2026\budget.xlsx`
- the date and time when the file was last correct
- whether the restored copy should replace the current file or be saved next to it

Restores are usually done within one working day.

## Laptop files that were not in OneDrive

Files saved only on the laptop (Downloads, C: drive) are not backed up. Save work files in
OneDrive or on the S: drive.
