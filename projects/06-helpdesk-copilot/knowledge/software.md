# Installing software

Staff do not have administrator rights on company laptops. This keeps malware from installing
itself. Approved software installs without IT through the Company Portal.

## Install an app from the Company Portal

Open **Company Portal** from the Start menu, search for the app (for example Zoom, Adobe
Acrobat Reader, 7-Zip, WireGuard) and click **Install**. The installation runs in the
background; you can keep working.

## Request software that is not in the Company Portal

Send the IT desk the name of the program, a link to the vendor and why you need it. If it
needs a paid licence, add your manager's approval. IT checks the security and licence terms
and adds approved software to the Company Portal for everyone, usually within three working
days.

## An app asks for an administrator password

Do not try to bypass it. Cancel the installation and request the app from the IT desk as
described above. Updates of installed apps run automatically every night.
