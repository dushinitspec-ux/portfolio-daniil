# Shared mailboxes in Outlook

Shared mailboxes such as **info@**, **bookings@** and **invoices@sample-office.example** are
read by several people. Access is given by IT after a request from your manager.

## Shared mailbox does not show in Outlook

After access is granted, Outlook for Windows adds the shared mailbox in the left folder pane
by itself, usually within an hour. Restart Outlook if it does not appear. In the new Outlook
and Outlook on the web, right-click **Folders → Add shared folder or mailbox** and enter the
address.

## Send email from a shared mailbox

In a new email click **From**, then **Other email address**, and type the shared address, for
example bookings@sample-office.example. If the From field is hidden, enable it under
**Options → Show From**. Sent emails are stored in the Sent Items of the shared mailbox.

## Shared mailbox on a phone

The Outlook app on iPhone and Android can open shared mailboxes: tap your profile picture,
**+ → Add shared mailbox**. The built-in Mail apps of the phones cannot.

## Request access for a new colleague

The manager emails the IT desk with the colleague's name, the shared mailbox and whether they
need to read only or also send. Access is usually ready the same working day.
