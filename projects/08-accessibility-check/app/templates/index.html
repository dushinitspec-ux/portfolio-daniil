What this tool does and does not do

It reads the HTML of each page and checks things that can be decided from the markup: text alternatives, labels, page titles, language, link texts, zoom, landmarks, frames, autoplay and inline colour contrast. Each finding names its WCAG 2.2 success criterion.

It cannot see the rendered page, keyboard behaviour, focus order or what a screen reader really announces. A clean report is a good start, not proof of accessibility or of compliance with the European Accessibility Act. Test manually and with tools such as axe DevTools as well.
